# tamasrazim.github.io

Official personal website of **Robiul Rumman Razim — Tamasrazim**.

## Structure

- `index.html` — main identity site
- `assets/css/site.css` — homepage styling
- `assets/js/boot.js` — no-JavaScript-safe boot class
- `assets/js/site.js` — homepage interactions and motion
- `renderer/` — Animation Renderer — Tamasrazim
- `renderer/css/app.css` — renderer UI styling
- `renderer/js/app.js` — renderer UI and export logic
- `renderer/sw.js` — renderer PWA service worker
- `renderer/manifest.webmanifest` — installable PWA manifest
- `og-image.png` — social preview image
- `robots.txt` / `sitemap.xml` — search discovery
- `404.html` — branded GitHub Pages fallback

No CI workflow is included in this repository.
