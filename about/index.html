02 / ABOUTPERSON / CONTEXT

A bit
about me.

I'm Robiul Rumman Razim. I use Tamasrazim online.

I build software across native Windows applications, games, browser tools, and creative work. Some projects are ready to use; others are unfinished. I'd rather show what's real than make unfinished work sound finished.

I grew tired of subscription-heavy software and the time spent searching for capable free alternatives. When existing tools do not meet my needs, I build my own—so I can spend more time creating and less time searching.
