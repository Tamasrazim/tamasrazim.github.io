I’m Robiul Rumman Razim, known online as Tamasrazim. I’m studying for a Diploma in Computer Science and exploring how software, visual systems and interactive ideas become useful things.

01 / Biography

Learning in public. Building with intent.

My work sits where software and creativity meet. I like exploring how an idea can become a real tool: a browser-based animation renderer, a game system, a desktop utility, a graphics experiment or a collection of reusable visual assets.

I tend to think about the whole experience rather than one isolated feature: its interface, workflow, file formats, documentation, performance and how another person would actually use it. A feature is not much use if its button does nothing, the export is broken or the interface hides the important settings.

I’m not presenting myself as an all-knowing engineer. I’m learning, testing ideas, working through bugs and developing my technical judgement through projects. Some ideas are ambitious; some are prototypes. I want the work to make those distinctions clear.
