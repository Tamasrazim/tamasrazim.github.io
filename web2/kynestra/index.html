KYNESTRA brings projects, task records, render jobs and creative modules around one shared Rust core. The aim is to make separate workflows work together without each keeping its own isolated state.

01 / Shared core

One place for project state.

The Rust core keeps project state and task records together, stores local metadata in SQLite and defines how modules register and exchange events. The idea is to make the working parts understandable and composable instead of hiding every operation behind one large interface.

Core

Packages

03 / Status

Alpha means unfinished.

KYNESTRA is still in alpha. The core and module contracts are taking shape; platform integrations, broader testing and stable v1.0 packaging remain work in progress. Its current release page is the place to check the available Windows x64 package and release information.
