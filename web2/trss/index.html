TrSS — Tamasrazim’s Real-time Scene Synthesis — explores guide-conditioned frame reconstruction and temporal stability. The long-term goal is a low-latency neural-rendering stage that complements a game’s existing renderer.

01 / Research question

Use the renderer’s context.

A screenshot does not contain every useful signal available to a renderer. TrSS investigates whether guide buffers and temporal context can help a reconstruction model recover detail while respecting the structure of the source frame.

The primary development target is an Intel Arc B580. That target is a research constraint, not evidence that the current implementation has been validated on the physical GPU or integrated into a released game.

02 / Input contract

Twenty channels of context.

The guide-conditioned model input combines noisy linear radiance, diffuse and specular albedo, normals, roughness, linear view depth, motion vectors, reprojected history RGB and a history-validity mask. Coordinate spaces and motion conventions are checked explicitly.

Model graph

A 20-channel guide-conditioned reconstruction graph with a four-channel residual/temporal-gate output head.

Baseline

A separate trainable 2× baseline reconstruction model.

Composition

The native backend composes the model residual with the current frame using the history-validity gate.

03 / Native handoff

Cooperative, not automatic.

The C++17 host SDK exposes a D3D11 bridge. A host submits frame resources and calls model-independent validation before processing the retained frame. The processing path packs the guide channels, runs the supplied OpenVINO model and uploads linear RGB into a host-owned RGBA32F shader-resource texture.

The bridge and host SDK have WARP integration tests using a deterministic synthetic CPU model. That verifies the cooperative API and its handoff, not a production model, an engine-specific plugin, automatic Present interception or physical Arc B580 performance. The diagnostic preflight and inference path currently use synchronous GPU-to-CPU readback.

04 / What remains

Research still has unknowns.

Training

No trained production checkpoint is bundled. Representative game-renderer training data is still missing.

Runtime

The current DXGI Present hook handles selected flip-model back buffers and conventional post-processing, but it does not call the new reconstruction bridge or upload reconstructed output into a game's presentation chain.

Integration

This is not yet a game-specific plugin, automatic game interception path or finished live-game renderer.

Validation

Visual quality, end-to-end latency and performance on the physical Arc B580 remain to be validated.
