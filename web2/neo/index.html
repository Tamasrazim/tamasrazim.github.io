04 / Native game / Windows

Space to think.
Systems to solve.

Windows x64C++ / CMake100 floors

NEO is a first-person puzzle game for Windows. Its structure is built around deterministic floors and a progression system that remembers the player’s run.

01 / Floor structure

One hundred repeatable spaces.

The game is organized around 100 deterministic floors, arranged across ten difficulty and theme tiers. A floor selector gives the player a way to revisit the structure, while progression tracks what has been unlocked and completed.

Floors

100 deterministic floors across ten tiers.

Objectives

Six objective types.

Progress

Unlocks, three-star ratings and saved progress.

02 / Controls and options

Built for desktop play.

View

First-person mouse-look with cursor release and pause behavior.

Display

Windowed, borderless and fullscreen modes.

Settings

Audio, hints, field of view, sensitivity and performance settings.

Build

Native Windows application written in C++ with a CMake build path.
