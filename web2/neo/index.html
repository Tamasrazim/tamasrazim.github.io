NEO is a native Windows first-person puzzle-game project built around structured floors, repeatable layouts and persistent progression.

NEO / Spatial studySPACE / LOGIC / PROGRESSION

01 / The idea

A puzzle space with memory.

NEO is a first-person puzzle-game concept where the structure of each floor matters and progression persists between visits. Its design focus is on readable spaces, clear rules and the satisfaction of understanding how a system behaves.

02 / Project direction

Build the rules first.

Deterministic floor behavior gives the game a repeatable foundation. Persistent progression provides continuity across those spaces. The project page and build status should be treated as the source for current implementation details as development continues.
