# Profile artwork

These illustrations are AI-generated, stylized character artwork used as supporting profile imagery for the Tamasrazim website's Schema.org Person entity. They are not documentary photographs.

- `01-full-body-front.webp` — full-body front view
- `02-left-side-portrait.webp` — left-facing side portrait
- `03-full-body-right-profile.webp` — full-body right-facing profile
- `04-full-body-back-view.webp` — full-body back view
- `05-three-quarter-portrait.webp` — three-quarter portrait

The site's existing `og-image.jpg` remains the primary social-sharing image and is retained in the Person schema image array.
