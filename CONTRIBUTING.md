# Contribution Policy

This repository is maintained as a proprietary project by Robiul Rumman Razim
(Tamasrazim).

The source is available for inspection, but it is not an open-source contribution
project. Do not submit copied code, extracted libraries, repackaged versions, or
derivative work for redistribution.

Unless explicitly invited, pull requests and patches are not accepted as permission
to reuse repository code or assets. Any separately authorized collaboration must have
written terms covering ownership and licensing.

See LICENSE and NOTICE.md for the repository-wide rules.
