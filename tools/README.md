# Tools

Repository engineering utilities live here.

## Categories

| Tool | Purpose |
| --- | --- |
| Asset validators | Validate Stock Asset Vault structure and metadata |
| Renderer validators | Check TRILYVA renderer contracts and behavior |
| EPS and code validators | Validate vector/export project assumptions |
| Generators | Produce large keyword or manifest datasets |
| Shared contracts | Definitions consumed by validation and build workflows |

## Boundary

/tools/ is for repository maintenance and engineering.

Public web applications belong in /projects/.

GitHub Actions definitions belong in /.github/workflows/.

/tools/ should not become a second project collection.
