What this tool measures
It measures the repository snapshot visible through GitHub's public REST API. “Tokens” means an estimate of how much text/code the current snapshot represents. GitHub does not expose an “AI token usage” number for repository storage, so this tool cannot report an official OpenAI/Claude billing count. API rate-limit information is shown separately so you can see how much GitHub REST access remains.
