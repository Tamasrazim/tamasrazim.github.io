What it does.

The implemented foundation is documented separately from roadmap items that are not yet complete.

01 / SYSTEMCORE

Project and task foundation

The Rust Core owns project lifecycle state, SQLite metadata, task persistence, module registry validation, and event contracts.

02 / SYSTEMCREATIVE MODULES

Forge, renderer, and Stock Vault

Built-in modules support file workflows, render jobs, asset ingestion, duplicate detection, and handoff between creative stages.

03 / SYSTEMPACKAGES

Portable project integrity

The documented package workflow includes .tamasrazim archives, required-file validation, and SHA-256 integrity checks.
