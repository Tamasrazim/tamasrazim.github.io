KYNESTRA.

I’m building KYNESTRA around a shared Rust core so projects, task records, render jobs and creative modules can work together instead of each keeping their own little island of state.

KYNESTRA is still in alpha. The core and module contracts are taking shape; platform integrations, broader testing and stable v1.0 packaging are still work in progress.

RUST CORE / MODULAR DESKTOP

Inside the KYNESTRA core.

Here’s the part that exists in the code now, rather than a list of everything I hope to add later.

01 / SYSTEMCORE

A shared project core

The Rust core keeps project state and task records in one place, stores local metadata in SQLite, and defines how modules register and exchange events.

02 / SYSTEMCREATIVE MODULES

Creative tools under one roof

The built-in modules cover file work, render jobs and asset intake. Duplicate detection and handoff between stages are part of the same workflow.

03 / SYSTEMPACKAGES

Projects you can check

The package workflow uses .tamasrazim archives and checks required files and SHA-256 hashes before trusting a project package.
