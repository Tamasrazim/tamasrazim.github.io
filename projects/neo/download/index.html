Up and running.

Pick the route that suits your setup. Download links above track the latest published release automatically.

01 / DOWNLOAD

Get the package

Use the recommended Windows installer, or download the portable ZIP and extract it completely to a folder.

02 / INSTALL

Run the setup

Open NEO-Setup.exe and follow the prompts. For portable mode, keep the included assets folder beside the executables.

03 / LAUNCH

Enter the vault

Start NEO from the installed shortcut. In the portable folder, launch neon_vault_updater.exe for the update-aware entry point or neon_vault.exe for direct launch.
