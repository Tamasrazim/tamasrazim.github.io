NATIVE GAME / WINDOWS

NEO.

I’m making NEO as a first-person puzzle game for Windows, with 100 deterministic floors to work through and a progression system that remembers your run.

The current build includes several objective types, mouse-look, saved progress and in-game settings. It is a native C++ game, with its own Windows build and release path.

Windows x64C++ / CMake100 floors
Download NEO ↗Other projects ↗

What you do on the floors

  • 100 deterministic floors arranged across ten difficulty and theme tiers
  • Six objective types and a floor selector
  • Unlocks, three-star ratings and saved progress

Controls and options

  • Mouse-look, with cursor release and pause behaviour
  • Windowed, borderless and fullscreen display modes
  • Audio, hints, field of view, sensitivity and performance settings

NEO runs as a Windows application. The download page is the place to check which build is available and what comes with it.
