NATIVE GAME / WINDOWS

NEO.

NEO is my native Windows x64 first-person puzzle game, built around a deterministic 100-floor progression system.

The game includes multiple objective families, native mouse-look, saved progress, settings, and a dedicated Windows release workflow.

Windows x64C++ / CMake100 floors
Download NEO ↗Other projects ↗

Game systems

  • 100 deterministic floors across ten difficulty and theme tiers
  • Six objective families and a floor selector
  • Persistent unlocks, three-star scoring, and save data

Controls and presentation

  • Native mouse-look with cursor release and pause behaviour
  • Windowed, borderless, and fullscreen display options
  • Audio, hints, FOV, sensitivity, and performance settings

This is a native Windows game, not a browser game. The release page is where to check current builds and downloads.
