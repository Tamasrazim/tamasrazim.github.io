TRILYVA KEYWORDS — 1 BILLION UNIQUE TOKENS
============================================

Corpus size: 1,000,000,000 globally unique keyword tokens.

LAYOUT
------
100 shard manifests are committed under:
  keyword-library/shards/KEYWORDS_001.txt
  ...
  keyword-library/shards/KEYWORDS_100.txt

Each shard represents exactly 10,000,000 entries.
100 shards × 10,000,000 entries = 1,000,000,000 unique entries.

UNIQUENESS
----------
Every generated token contains its absolute zero-padded 10-digit corpus index.
Therefore index N can occur exactly once, and no token can collide across shards.

Example:
  abstract0000000000
  prism0000000001
  vector0000000002
  ...
  [absolute index makes each token unique]

GENERATOR
---------
  tools/generate_1b_keywords.py

Generate shard 001:
  python tools/generate_1b_keywords.py --start 0 --count 10000000 > KEYWORDS_001.txt

Generate shard 100:
  python tools/generate_1b_keywords.py --start 990000000 --count 10000000 > KEYWORDS_100.txt

Generate any 1,000,000-token sample:
  python tools/generate_1b_keywords.py --count 1000000 > KEYWORDS_SAMPLE.txt

IMPORTANT
---------
The literal 1B-entry text corpus is NOT committed to GitHub. The repository stores
the deterministic generator and the 100 shard manifests because the full UTF-8
corpus would be many gigabytes and is unsuitable for normal Git hosting.

These are synthetic unique keyword tokens, not 1B distinct English dictionary words.
The semantic prefix comes from TRILYVA's keyword vocabulary; the numeric suffix is
the uniqueness mechanism.
