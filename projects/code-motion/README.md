# Code → Motion — Tamasrazim

Browser-first deterministic animation renderer and media-production project.

## Media stack

The project uses **Mediabunny 1.58.1** for the container/muxing layer and its WebCodecs integration.

- MP4
- Matroska / MKV
- WebM
- MOV
- additional media containers supported by the library

Target video codecs include:

- H.264 / AVC
- H.265 / HEVC
- AV1
- VP9
- VP8

The important distinction is that Mediabunny is not a collection of proprietary hardware encoder binaries. Encoding is performed through the browser's WebCodecs implementation when available, so Code → Motion probes the current device/browser before enabling a codec/configuration.

## Vendoring

GitHub Actions pins Mediabunny to **1.58.1**, downloads the npm package, and commits the browser bundle into:

`vendor/mediabunny/1.58.1/`

The vendor directory is generated by `.github/workflows/code-motion-media-stack.yml`.

## Renderer

The main renderer remains:

`../../code-motion-tamasrazim.html`

Its deterministic contract is frame-index driven:

`time = frame / fps`

The preview clock is never used as the export clock.
