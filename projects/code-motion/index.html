01 / RENDER MODEL

Every requested frame is explicit.

The export clock is derived from the frame index rather than realtime playback:

time = frame / fps

Preview playback and export are separate systems. Rendering can take longer on heavy compositions without silently dropping requested frames.

02 / MEDIA STACK

Encoder + container are separate layers.

WebCodecs provides browser/device encoder access. The workspace uses local MP4/WebM muxing paths implemented by the renderer.

03 / CAPABILITY DETECTION

No imaginary codecs.

The workspace probes the selected resolution, frame rate and codec against the current browser before enabling a render path. Unsupported combinations remain visibly unavailable instead of producing fake files.
