01 / FRAME MODEL

Time is derived from frames.

Export follows time = frame / fps, keeping preview playback separate from deterministic generation.

02 / MEDIA LAYER

Encode first. Package second.

The renderer probes browser codec support, then uses the matching local container path for the requested output.

03 / CAPABILITY

Actual browser support.

Unsupported resolution / FPS / codec combinations are surfaced before render rather than simulated as available.

04 / SURFACE

Everything runs in the browser.

The project uses local execution and keeps its renderer assets self-contained. The canonical renderer remains the working source.
