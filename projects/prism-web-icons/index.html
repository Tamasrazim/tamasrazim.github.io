Prism Web Icons.

I built Prism Web Icons around a simple visual rule: geometric icons should feel like they belong to the same family, not a folder of unrelated downloads.

The project focuses on drawing and exporting SVG icons. I still review the shapes and metadata before using a set in a product or submitting it to a marketplace.
