DOT MESH FLOW — EXAMPLE ASSET
=============================

Video example prepared separately: 3840 × 2160 (4K UHD), 60 fps, 12 seconds, H.264 MP4.
The loop uses a cyclic phase across 720 frames. Check the encoded video at the boundary before marketplace submission.
Vector stills in this folder: EPS and SVG contain editable circles, not an embedded raster image.

The MP4 is the animation. EPS is a static illustration format and contains one representative frame only; it cannot contain a 12-second animation. The online example previews the motion and exports the current frame as vector SVG or EPS.

The metadata.json file contains a proposed title, description, and 45 suggested search keywords for the animated video. Verify marketplace requirements before submission.
The downloadable Dot Mesh Flow example bundle also includes the H.264 MP4 and a transparent PNG reference. Those video/raster files are packaged separately from this website directory; the EPS and SVG above are the files mirrored here.
