# Projects

This directory is the public project collection for Tamasrazim.

It contains 1,200+ individual project folders. Most projects expose an index.html entry point so their public route remains predictable:

/projects/<project-name>/

## Main families

### Creative and rendering
- code-motion
- code-to-eps
- code-to-svg
- animation, vector, media and export utilities

### Web platform and diagnostics
- browser capability tests
- accessibility audits
- CSS/HTML utilities
- networking and HTTP tools
- storage, media and API experiments

### Data and file tooling
- CSV utilities
- encoding and decoding
- metadata tools
- file and archive planning utilities

### Applications and products
- bncagrocare
- razim-fps
- repo-token-meter

## Project rule

A project should normally keep its implementation, manifest, icons, service worker and project documentation inside its own folder.

Do not add shared repository tooling here unless it is part of a public project.

## URL rule

Project names are public URLs. Renaming or moving a project requires a redirect or migration plan rather than a silent folder move.
