# Selected projects

This directory contains a curated set of first-party browser tools, native applications, games, and creative experiments. It is not a dump of automatically generated micro-tools.

## Featured project families

- **TRILYVA** — browser-based procedural motion workspace with renderer and batch surfaces.
- **Vector tooling** — CODE → SVG and CODE → EPS.
- **NEON VAULT** — native Windows x64 first-person puzzle game.
- **TUNRUN** — native C++20 tunnel-runner game in development; its project page separates plans from implemented work.
- **KYNESTRA** — architecture, modules, desktop work, and format specifications.
- **Business software** — BNC AgroCare catalogue and invoice workflow.
- **Browser tools** — Format Forge, Repo Token Meter, MailScope, and Stock Asset Vault.
- **Creative experiments** — Prism Web Icons and Spiral Mic.

## Project rule

A selected project should have a clear purpose, a real route, accurate status, and supporting files kept within its product boundary where practical.

Shared repository tools belong in the tools or scripts directories, not among project routes.

## URL rule

Established routes for retained projects are public URLs. The former generated one-page utility routes have been removed; the project directory now links only to maintained projects.
