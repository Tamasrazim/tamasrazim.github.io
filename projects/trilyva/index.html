How TRILYVA works

TRILYVA uses the browser's real media and encoding support. Available exports depend on your browser and the settings it can handle.

01 / CODE

Write the motion, not every keyframe

Animations are driven by code and reusable logic, which makes it easier to describe a pattern than to place every frame by hand.

02 / PREVIEW

Preview performance is separate from export

At demanding resolutions, frame rates, or bitrates, the live preview may lag as your system works harder. Preview stutter affects responsiveness; it does not determine the final export's frame sequence.

03 / RENDER

Every requested frame is rendered individually

TRILYVA exports from the requested frame sequence rather than recording the live preview in real time. The exporter processes frames by index and verifies the resulting sample count; preview lag alone does not cause frames to be skipped in the final export. If verification detects a mismatch, the output is not marked as valid.

04 / OUTPUT CAPABILITIES

Up to 16K, 240 fps and 2 Gbps

TRILYVA provides settings for output up to 16K resolution, 240 frames per second, and a target bitrate of 2,000 Mbps (2 Gbps). These are upper configuration limits, not a guarantee that every combination will encode on every device. Actual availability depends on browser and codec support, hardware, memory, and operating-system limits.

05 / VIDEO

Use an export path the browser supports

Encoding and container output are handled separately. H.264/AVC and VP8/VP9 paths are offered when the browser supports them.

06 / AUDIO

Offline Voice Studio

I also built an offline voice studio using formant synthesis. It can produce timed dialogue, a procedural soundscape, a five-minute PCM WAV and subtitle cues; the voice is intentionally synthetic, not a neural voice clone.

07 / MOVIE

Local Movie Finalizer

The local finalizer combines a video or stock clip with a browser-decodable audio file. MP4 depends on recorder support; automatic mode can fall back to WebM. It captures and re-encodes in real time, so this isn't a lossless muxer.

08 / VECTOR

Creative export workflows

TRILYVA sits alongside my vector tools and stock-asset workflow, but those tools keep their own pages and workspaces.

09 / LIBRARY

Render a complete library

Choose a built-in or imported JavaScript library, then export the collection into a folder or ZIP. Each item receives its own video, selected still frames, and metadata files.

10 / STILL FRAMES

PNG, JPG, SVG and EPS

Select a frame index and the still formats you need. PNG is selected by default; vector exports depend on the drawing operations supported by the vector recorder.

11 / INSTALL

Browser-first delivery

Open the renderer in a supported browser. Export options vary by browser and hardware, and folder/ZIP destination pickers require compatible browser support.

Frame model

The preview can prioritise responsive playback. Export follows the requested frame sequence instead.

TIMEBASE

time = frame / fps

Every output frame has a position in the requested timeline. Rendering slowly should not change where that frame belongs.

SEPARATION

A preview is not a render

Playback can skip ahead to stay interactive; offline rendering works through the requested frames one by one.

VALIDATION

Honest capability checks

The app checks the browser's encoder capabilities before offering a resolution and frame rate for export.
