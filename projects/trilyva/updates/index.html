Current progress

The desktop release is being tracked separately from the existing browser app. Status labels describe implementation and publication state; planned capabilities are not advertised as already shipped.

01 / FOUNDATION

Product architecture

Direction defined: retain the current interface and connect it to a Rust backend through Tauri commands and events. No redesign of the existing workspace is part of this track.

STATUS / SPECIFICATION DEFINED
02 / DESKTOP SHELL

Rust + Tauri integration

The desktop shell must preserve the current editor, preview, panels, and animation behaviour while adding desktop process and file management.

STATUS / NOT YET RELEASED
03 / RENDER ENGINE

Deterministic frame pipeline

Target design: render each requested frame by index and timestamp instead of recording live preview playback. Output verification must reject incomplete renders.

STATUS / IMPLEMENTATION TO VERIFY
04 / MEDIA BACKEND

FFmpeg + FFprobe

Planned encoding layer with runtime capability discovery, validated encoder settings, useful diagnostics, cancellation, and inspection of completed files.

STATUS / PLANNED
05 / DISTRIBUTION

Installers and updates

Platform-specific packaging, signatures where applicable, release assets, checksums, and version notes must be produced and tested before a package is listed as available.

STATUS / NO PUBLIC BUILD
06 / RULE OF RECORD

Only verified features count

Every OS label and download link on this page will be driven by release evidence. A roadmap target is never shown as a shipped capability.

Media pipeline goals

These are planned desktop goals. Exact support will come from the actual FFmpeg build, the selected encoder, and the host hardware—not from a fixed marketing list.

ENCODERS

Software and hardware paths

Target discovery of available H.264, HEVC, AV1, VP9, and other FFmpeg encoders. Hardware paths such as QSV, NVENC, AMF, and VideoToolbox are conditional on the platform, driver, build, and GPU.

ROADMAP / CAPABILITY-DEPENDENT
CONTAINERS

Flexible output formats

Target container options include MP4, MOV, MKV, WebM, and AVI where the packaged muxers and selected codec combination support them.

ROADMAP / NOT YET VERIFIED
FRAME SEQUENCES

Images and transparency

Target PNG/JPEG sequences and selected still formats. Alpha export depends on the actual encoder, pixel format, and container. Unsupported options must be clearly rejected.

ROADMAP / FORMAT-DEPENDENT
DETERMINISM

Frame count and timestamps

The planned render pipeline must process the requested frames in order, independently from preview playback, and validate the output before reporting success.

ROADMAP / TESTS REQUIRED
HIGH-END OUTPUT

16K · 240 FPS · 2 Gbps

These are design targets, not universal promises. Usable combinations will depend on memory, frame buffers, encoder limits, hardware, storage, and output format.

TARGET / NOT A PERFORMANCE GUARANTEE
RELIABILITY

Verified, cancellable jobs

Target job progress, cancellation, bounded-memory transfer, error diagnostics, output inspection, and cleanup after failed or interrupted renders.
