14 / NATIVE ANDROID GAME

PHASE
BREAK

Two realities share one route. Jump, switch phases mid-air, collect prism shards, and reach the gate.

A new mobile game built as an installed Android application in Kotlin. It draws and simulates its world locally, saves progress on the device, and does not need an account or network connection.

SOL / UMBRAPHASE ENGINE / 01

One route.
Two realities.

Each room asks you to read the path, time a jump, and switch which geometry is solid before you land. The active world is bright; the inactive route remains faintly visible.

01 / SOL

Light phase

Bright platforms hold the player. Switching out of SOL while standing on one means you must find another surface before gravity takes over.

02 / UMBRA

Shadow phase

Shadow platforms become solid on a phase swap. Change worlds in mid-air to reach a route that was only a ghost a moment ago.

03 / PROGRESSION

Shards and checkpoints

Collect prism shards, cross hazard sections, activate checkpoints, and clear the exit gate. Unlock progress is saved locally between sessions.

Built for
the phone.

No browser wrapper and no remote service in the gameplay path. Rendering, physics, touch input, level generation, and local saves run in the Android app.

PLATFORM

Android APK

Landscape-first controls designed for touch. Minimum Android version is 6.0 (API 23); the source targets Android SDK 35.

ENGINE

Kotlin + Canvas

A native drawing and game loop with collision checks, phase-aware platforms, hazards, pickups, camera tracking, and a 60 FPS render cap.

PRIVACY

Offline by design

No network permission, account flow, advertising SDK, analytics dependency, or subscription requirement. Progress stays in local app storage.

BUILD / ANDROID

Installable test APK

DEBUG SIGNING

The repository's Android workflow assembles app-debug.apk whenever the game source changes. Open the build-status link above, select a successful run, and download the phasebreak-debug-apk artifact. The debug package is for direct device testing; a Play Store release needs a separately managed private signing key.
