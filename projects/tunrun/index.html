TUNRUN.

I'm building TUNRUN as a native C++20 tunnel-runner.

I want each run to be procedural, with controls that feel right on keyboard, mouse, and gamepad. This page documents the direction, not a finished release.

Planned gameplay

  • Procedurally generated runs and replayable routes
  • Keyboard, mouse, and gamepad interactions across menus and gameplay
  • Different ships with distinct handling or play styles

Progression goals

  • Local save data for progress and unlocks
  • Run pickups and rarer upgrade resources
  • Testing, balancing, and reliable input behaviour before calling the game finished

Local saves, unlockable ships, and a progression system are goals for the project, not a claim that every feature is already implemented. It isn't a playable browser build or a release download.
