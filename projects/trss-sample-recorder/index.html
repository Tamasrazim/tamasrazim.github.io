TrSS Sample
Recorder.

A small native Windows app for finding installed games, launching them from a library, and collecting a bounded sample of what is visible while you play.

A 120-second warm-up begins after a visible window belonging to a detected game is found. No screenshots are stored during that period. It is designed as a normal Windows GUI: no terminal, Python install, service, or automatic upload.

The capture loop.

Three predictable stages keep the recorder quiet before play and cap each file size.

01 / DISCOVERLOCAL LIBRARY

Detect installed games

Scans common Steam, Epic, Ubisoft Connect, EA, GOG, Xbox and local game locations, plus Windows uninstall entries. Detection is best-effort, not universal.

02 / WAIT120 SECONDS

Let the game settle

The warm-up begins when a visible window belonging to a detected installed game is recognized. No sample images are written until the timer finishes.

03 / SAMPLEUP TO 2 FPS

Capture the foreground

Only the selected game in the foreground is sampled. JPEG images are limited to a 1920-pixel longest side and embedded as Base64 in JSON.

Every JSON chunk has a hard ceiling.

Completed files are standalone documents—not a log that grows forever.

SIZE24,117,248 BYTES

23 MiB maximum

Completed chunk-####.json files stay at or below 23 MiB. When a chunk reaches the cap, it is finalized and the next numbered chunk begins.

SAFETY.JSON.PART

Finalize before sharing

Files are first written with a temporary .json.part suffix and renamed only after closing JSON is written. Do not upload incomplete part files.

CONTENTSPIXELS + TIMING

Useful provenance

Each chunk records session and game identifiers, frame timestamps, image format and dimensions, plus best-effort CPU/memory readings. Missing measurements stay null.

RGB capture, not a game hook.

The capture limits are explicit so the files are not mistaken for ground-truth renderer data.

LOCAL-FIRSTNO NETWORK

You decide what to upload

Samples stay local until you copy or upload them. Review images before sharing; visible chat, player names and overlays may appear in captures.

NO INJECTIONRGB ONLY

No hidden game buffers

The recorder does not inject into games or read their memory. It cannot obtain depth, motion vectors, camera matrices, temporal history or original render targets.

TRSS WORKFLOWEXPERIMENTAL

Import, train, evaluate

TrSS includes an importer for completed chunks and an RGB-only experiment. That is not proof of live neural rendering or validated Arc B580 performance.
