QALYVYRON

A 3D creation studio built around a simple idea: make the first five minutes feel obvious, then reveal deeper tools as you grow.

QALYVYRON is a local desktop application for building and editing 3D scenes and rendering still images. It is being developed as an independent alternative—not a clone of Blender's interface, and not yet a complete replacement for Blender.

01 / THE FIRST SESSION

Simple first.
Power when needed.

The current main build starts with one shape, explains the basic mouse controls, and keeps advanced parameters out of the way until they're useful.

01 / START

A guided first run

A welcome screen and four-step tour cover adding shapes, moving around the scene, changing appearance, and saving or rendering.

02 / MOVE

Work with the mouse

Drag a shape to move it, right-drag empty space to look around, and scroll to zoom. Numeric transforms remain available in the full-tools layout.

03 / LOOK

Visible colour and size

Simple view exposes clickable colour swatches and a size slider. Detailed material, camera, and light controls live behind “Show all tools.”

02 / WORKING SYSTEMS

Actual geometry.
Actual output.

These are current implementation paths, not promises based on mock controls. Import support and render capabilities still have clear limits.

01 / SCENE

Live 3D workspace

  • Cube, sphere, cylinder, cone and plane.
  • Object list, selection, transforms and material colours.
  • Focus Selected and Frame All bring the camera back to the right place.
  • Local scene save/open and bounded undo/redo.
02 / MESH

Editable polygon geometry

  • Clickable viewport vertex markers and selectable mesh-edge lines.
  • Select a closed edge loop to create supported planar, convex faces.
  • Native validation rejects open, duplicate, branched and disconnected selections; boundary fills keep consistent face winding.
  • Face creation, extrusion, inset, merge and delete for supported topology.
  • Geometry-only Wavefront OBJ import and transformed OBJ export.
03 / ASSETS

Bring in 3D files

Local OBJ geometry becomes editable mesh data. GLB and glTF files can be loaded for scene preview, but currently remain read-only and reference their original local files.

04 / RENDER

Offline PNG output

A separate CPU renderer uses scene triangles, BVH acceleration, multisampling, directional and point lights, hard shadows, and simple diffuse indirect bounces. It reports progress and supports cancellation.

05 / CONTROL

Save and recover locally

Unsaved scenes receive local recovery snapshots approximately every 30 seconds. On the next launch, a prompt offers to restore the snapshot. Saving or explicitly discarding clears the recovery copy, which stays separate from the original scene file.

06 / OUTPUT

Choose a still-image size

Render settings include 720p, 1080p, 1440p, 4K and 8K, with caps on pixel and ray workload to keep unsafe jobs bounded.

03 / WHAT ISN'T DONE YET

A realistic status.

Beating a mature tool means doing the hard engineering as well as making the UI approachable. The missing systems are part of the plan, not hidden in fine print.

MODELLING / MATERIALS

Depth still to build

  • Complete vertex/edge/face editing, edge operations, bevel and loop tools beyond the initial edge-loop face workflow.
  • Non-destructive modifier stack, UV editing and node-based materials.
  • Texture, normal and material-library preservation in imported models.
RENDER / ANIMATION

Production pipeline still to build

  • Soft shadows, denoising, richer PBR and imported-asset geometry in final rendering.
  • Timeline, keyframes, animation export, rigging and simulations.
  • Self-contained asset collection and release-grade installer validation.
The offline renderer currently skips runtime-loaded GLB/glTF geometry. OBJ import is geometry-only: UVs, MTL materials, and textures are not preserved yet. Export Preview is a live viewport capture; Render Image is the separate offline renderer.
