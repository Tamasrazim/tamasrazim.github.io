Privacy · Browser preview

Your reading space.
Your device.

The current SORYVYN preview is designed around local browser storage. It does not require an account.

What this preview stores

Saved titles, favorites, recent reading activity, sample reading progress, enabled sample sources, theme preference, and whether the preview notice was dismissed may be stored in your browser's local storage under soryvyn.web.chunk01.

This data stays in the browser profile on this device. Clearing site data or switching browser profiles can remove or separate it.

Network activity

The current prototype uses fictional sample titles and sample source profiles. It does not fetch manga pages from source websites, create a SORYVYN account, or send your search terms, favorites, bookmarks, or reading progress to a SORYVYN backend. JSON backups created from My Library are downloaded directly by your browser and are not uploaded to SORYVYN. Local page collections are also saved in browser-managed storage on this device; the JSON backup contains preferences and progress, not those page files.

The website is intended to be hosted by GitHub Pages. The hosting provider may process standard request and security information under its own terms and privacy policy.

Offline storage

When available, the service worker caches the application shell so the interface can reopen offline. Cached application files and local preferences may remain until the browser removes them or you clear the site's stored data.

Future versions

Live source connectors, imports, downloads, analytics, accounts, synchronization, and native builds are not part of this preview. Before any feature introduces additional data collection or third-party network activity, this notice should be updated to explain it.
