Format Forge.

One browser workspace for turning files into other useful formats. Drop files, choose an output, convert locally when the browser can do it, and download the result.

Queue

Browser-native

Images and structured text/data are processed directly in the page without uploading the source file.

Media engine

Video and audio use FFmpeg WebAssembly when the required engine is available.

Honest matrix

Not every format can meaningfully convert to every other format. Unsupported pairs are blocked instead of faking a result.

Privacy: files stay in your browser for the conversion flow. Media-engine conversions may download the FFmpeg runtime from the public CDN; the selected source file is processed locally by that runtime.
