CREATIVE TOOL / BROWSER WORKSPACE

Format Forge.

I built Format Forge to put the file tasks I reach for most often in one browser workspace. Pick a file, use a tool that supports it, and save the result locally.

Format Forge works with files you choose on your device. What it can convert depends on the format and the tools available in the current browser.

LOCAL FILE WORKFLOW

File jobs, in one place.

The goal is to make the supported jobs easier to find—not to pretend one converter can handle every format.

01 / SYSTEMINTAKE

Start with your files

Choose files from your device, then pick a tool that matches the file type. There is no account step in the middle.

02 / SYSTEMTOOLS

Convert or bundle

The current workspace includes supported conversion tools alongside ZIP and document utilities.

03 / SYSTEMOUTPUT

Check the result

Pick the output option, check the result, and save it locally. Very large jobs still depend on the browser and the machine running it.
