# NEON BREACH

A native 3D first-person arena shooter for Windows.

## What it is

NEON BREACH is a small, complete FPS built from C++ and raylib. It is intentionally asset-free: the environment, enemies, weapon, crosshair and effects are generated by code, so the Windows package does not depend on a content server.

## Gameplay

- First-person mouse look
- WASD movement
- Shift sprint with stamina
- Hitscan shooting
- 12-round magazine + reserve ammo
- Reloading
- Enemy collision/chasing
- 4 escalating waves
- Health and damage feedback
- Wave transitions
- Pause menu
- Win/lose screens
- 144 FPS target
- Resizable window
- Native x64 Windows build

## Controls

WASD = move, mouse = aim/fire, Shift = sprint, R = reload, Esc = pause/resume or quit, Enter = start/restart.

## Build locally

Prerequisites: Windows 10/11 x64, Visual Studio 2022 with Desktop C++ workload, and CMake 3.21+.

Run build.ps1 with PowerShell. CMake downloads raylib 5.5 during configuration and builds the game as a static executable.

## Windows installer

Every push to main that changes this project runs the Windows build workflow. The workflow produces an installer and a portable ZIP, then publishes both to a GitHub Release.
