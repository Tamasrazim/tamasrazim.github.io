Gameplay calculations:
- 58 x 58 deterministic BFS grid for start-to-exit and object reachability
- finite-value and in-bounds guards run before grid-cell conversion
- intentional outer-shell corner joins are excluded from internal wall-overlap failures
- objective inventory counts are checked against each floor's actual objective
- memory fragment order is unique and contiguous; failed inputs restore the fragments
- Floor 100 is a combo challenge: four crystals, four switches, one keycard and four ordered fragments
- moving collision uses short axis-separated substeps to reduce tunnelling
- hazard spawns reject walls, interactables, start/exit safety zones and other hazards
- repair uses signed fallback coordinates and preserves the assigned objective
- mouse uses native disabled-cursor input with no pointer warp
- pickups and switches produce fractured-piece/particle feedback
- 4-second procedural beat layer loops separately from the original soundtrack
