# Tamasrazim cinematic portfolio

A standalone, dependency-free portfolio experiment for the Tamasrazim site. This folder stays separate from the production homepage.

## Preview locally

Serve this folder with any static HTTP server and open its `index.html`. For example, from the repository root:

```sh
python -m http.server 8080
```

Then visit `http://localhost:8080/cinematic-portfolio/`.

The scene uses native WebGL and deterministic geometry. It does not load third-party JavaScript, use runtime AI services, or require a build step. If WebGL is unavailable, the semantic project sections and CSS fallback remain available.
