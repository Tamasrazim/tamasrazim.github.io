# Security Policy

## Reporting a vulnerability

Please report security issues privately through **GitHub Security Advisories** for this repository.

Do not publish sensitive vulnerability details in a public issue.

When reporting, include the affected project/path, a clear description of the issue, reproduction steps when available, and the potential impact.

## Scope

This repository is primarily a static GitHub Pages site and a collection of browser-based applications. Some projects use local browser storage, Web APIs, third-party browser libraries, or GitHub Actions.

Security reports about any of those components are welcome when they affect this repository or its published applications.

## Supported state

Projects are maintained from the `main` branch. Individual project READMEs and validation scripts are the authoritative place for project-specific behavior and compatibility details.
